# QR-Based Autonomous Navigation and Mapping Performance Report

## Overview

This study evaluates the performance of an autonomous robotic system performing navigation between QR-defined waypoints using LiDAR-based SLAM for localization and path planning, combined with vision-based QR detection.

The objective was to analyze traversal efficiency, repeatability, and system behavior across multiple runs, including iterative looped traversals (“training runs”) and a final evaluation after stabilization.

---

## Experimental Setup

Experiments were conducted in an indoor basement environment characterized by:

- constrained geometry and narrow corridors  
- presence of static obstacles (walls, equipment, furniture)  
- limited structural diversity and repetitive features  

The robot executed the following sequence:

1. Start from an initial position  
2. Navigate to the first QR code  
3. Detect and scan the QR code  
4. Navigate to the second QR code  
5. Perform repeated looped traversals between QR locations  
6. Execute a final evaluation run after multiple iterations  

QR detection occasionally required repositioning to obtain a favorable viewing angle.

---

## Results

### First Training Run (Loop Routine)

- Start → First QR: **55 seconds**  
- First → Second QR:  
  - Initial approach: **2 min 11 sec**  
  - Additional alignment: **+12 sec**  
- Return to First QR: **2 min 23 sec**  
- Return to Second QR: **1 min 40 sec**

---

### Second Training Run (Loop Routine)

- Start → First QR: **22 seconds**  
- First → Second QR:  
  - Initial approach: **37 seconds**  
  - Additional alignment: **+19 sec**  
- Return to First QR: **1 min 43 sec**  
- Return to Second QR: **1 min 11 sec**

---

### Final Evaluation Run (Post-Training Performance)

- Start → First QR: **10 seconds**  
- First → Second QR (including scanning):  
  - Initial approach: ~30 seconds  
  - Additional alignment: ~20 seconds  
  - Total: **~50 seconds**

---

## Performance Analysis

### 1. Improvement Across Runs

A clear reduction in traversal time is observed:

- First QR:  
  - 55 sec → 22 sec → **10 sec**
- Second QR:  
  - ~2+ min → ~56 sec → **~50 sec**

This indicates improved consistency in:

- localization  
- path execution  
- system responsiveness  

Repeated traversal improves operational stability even without explicit learning.

---

### 2. QR Detection Behavior

The second QR consistently required additional time for detection due to:

- suboptimal initial viewing angle  
- sensitivity of QR decoding to camera alignment  
- small positional or orientation errors at the goal  

---

### 3. Navigation and Return Path Efficiency

Return paths were consistently longer than forward paths, especially in earlier runs. This is likely due to:

- accumulated localization drift  
- conservative obstacle avoidance  
- non-optimal orientation after reaching QR waypoints  

---

### 4. Environmental Effects

The basement environment introduces several challenges:

- repetitive geometry reduces SLAM distinctiveness  
- narrow spaces constrain feasible trajectories  
- nearby obstacles frequently trigger avoidance behavior  

These factors contribute to:

- invalid start or goal conditions  
- infeasible trajectory optimization (QP failures)  
- increased traversal time  

---

## Mapping Considerations

Mapping quality is critical for reliable navigation.

Navigation issues such as:

- invalid goals  
- infeasible trajectories  
- inconsistent behavior  

are often caused by insufficient or low-quality maps.

This may occur if:

- the environment is not fully covered  
- the robot moves too quickly during mapping  
- mapping is performed too close to obstacles  
- the environment changes after mapping  

### Recommendation

It is recommended to **recollect the map periodically**, especially when:

- navigation performance degrades  
- localization becomes unstable  
- obstacle avoidance becomes overly conservative  
- the environment layout changes  

A well-constructed map significantly improves localization accuracy and planning reliability.

## Conclusion

The system successfully demonstrated autonomous navigation between QR-defined waypoints, with significant improvement across repeated runs.

The final evaluation showed efficient traversal and consistent behavior, indicating stabilized localization and planning.

However, performance remains sensitive to:

- environmental complexity  
- QR viewing geometry  
- mapping quality  

Ensuring accurate mapping and maintaining safe distance from obstacles are key to reliable operation.

Overall, the results confirm the effectiveness of combining LiDAR-based navigation with vision-based QR waypoint detection, while highlighting areas for further optimization.
